# Team 404 FireWatch

**Turning Earth Data Into Intelligence**

TerraSignal FireWatch is a prototype web application developed for the NASA Space Apps Challenge 2026.

The project focuses on harmonizing NASA MODIS and VIIRS satellite fire detection records to provide a clearer view of historical fire activity.

## Project Objective

To develop an interactive fire activity calendar that allows users to:

- Explore satellite-detected fire activity by region and date.
- Compare MODIS and VIIRS fire detections.
- View harmonized fire detection records.
- Explore historical fire activity.
- Compare selected periods against multi-year averages.

## Data Source

NASA Fire Information for Resource Management System (FIRMS).
